## B2 偏差记录（实现与稿子的差异，逐条）

| # | 偏差 | 原因 | 是否回改设计 |
|---|---|---|---|
| B2-a | 标题行之上仍有外壳预览板与 caption | 稿子没画预览板；改色要立刻看到键盘跟着变（D2 像素闸门的前提），且外壳 `ThemeEditorActivity` 自带 | 否 |
| B2-b | 舞台皮肤隐藏外壳 Toolbar，标题行右侧多 ⋯ 菜单 | 稿子没有顶栏；收起 ActionBar 后「切换配色 / Material You / 目录」必须有入口（B1 `heroMenu` 同一模式）。非舞台皮肤仍显示 Toolbar | 否 |
| B2-c | 巨型色块字色按亮度自适应（深底白字 / 浅底深字） | 稿子写死白字，但模板主题 `back_color` 是 `0xFFEEEEEE`，白字会消失；54 个键什么颜色都有 | 否 |
| B2-d | 「方案」段是自拟卡（方案名 / ID / 未设数 / 预览明暗 / dock 说明） | 稿子只画了前三个颜色段；「预览明暗」是「行里的色与键盘不同」的唯一解释，必须落在一屏上 | 否 |
| B2-e | 副标题「7 组 · 54 个色值」、下一组「键盘 · 25 项」、dock「新建」 | 稿子的 8 组 / 12 项 / 长标签是示意；这里按真实主题的非空组数与各段项数算，dock 标签用短词避免挤 | 否 |
| B2-f | 「下一个组」在组末尾，不与色块卡同屏 | 稿子只有 3 行示意，真实组 15/25/14 项，一屏放不下 | 否 |
| B2-g | 平板两栏下表单列通栏（约 1697px），键名与右值分得较远 | 预览板必须通栏保像素闸门，表单限宽会让上下两截错位；小字发散留到 F6 的 G-05 五页一起评估 | 待 F6 |
| B2-h | 行间分隔线用 `ui_rule`（暗色下偏弱） | 稿子用 outlineVariant 60%；现有 token 里 `ui_rule_in_card` 在舞台皮肤是透明的，取它会整条消失 | 否 |

## B3 偏差记录（实现与稿子的差异，逐条）

| # | 偏差 | 原因 | 是否回改设计 |
|---|---|---|---|
| B3-a | 键盘左右不缩进，铺满舞台 | 计划 §4.1：预览宽度必须与输入法一致，差 1dp 键位重排 | 否（保 D2 像素闸门） |
| B3-b | 半卡有 3 行 6 张，稿子只有 2 张 | 编辑器的 6 个动作槽都要能改，后 4 个滑动槽沿用同一档卡片语言 | 否（功能不能少） |
| B3-c | 多一张「长按弹出 popup」满宽卡 | 稿子没画，但 popup 是真实字段，没地方改 | 否 |
| B3-d | 字段标题用小写 YAML 键名（label/width/click） | 键名就是要写进文件的那个，大小写敏感；稿子的大写是样式化 | 否 |
| B3-e | −/＋ 圆钮 36dp，稿子 30px | 触控下限 | 否 |
| B3-f | 大卡标题 10sp（稿子 CSS），其余字段标题 9sp | 稿子 `.b-bigin .lb` 是 10px、`.b-step`/半卡是 9px，照抄 | 否 |
| B3-g | 字重 640/680 → `sans-serif-medium`(500) | Android 字体族不提供任意字重；与 B1 的 34sp 标题一致 | 否 |
| B3-h | dock 字形用稿子的＋−←→↶↷，非图标库 | 六项并排，图标会挤；与 B1 的 glyph 方案一致 | 否（已在计划 §4.4 记） |
