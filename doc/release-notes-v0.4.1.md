# 同文编辑器 0.4.1

编辑同文输入法（Trime）主题的独立工具：改配色、改布局、改工具条。只做文本级修改，
预览与输入法同宽，改一项写一行。

## 这一版新增

### 动态配色（新入口）
- 工作台新增「动态配色」卡片：来源二选一（**系统壁纸** / **指定颜色**），
  浅色、深色两行色板先预览，再点「生成明暗两套」。
- 只新增 / 替换 `material_you` 与 `material_you_dark` 两套方案，
  **不动主题里其它任何方案**（包括 `default`）。
- 输入法快捷键 `DynamicColor` / `SaveDynamicColor` 仍然一键更新 / 收藏。

### 内置方案
- 随包提供 923 行全量参数模板；工作台「内置方案 → 保存到本地」一键复制到主题目录，
  只改 `name:` 一行，其余字节原样保留。
- 「新建」与「保存到本地」共用同一份模板。

### 主题管理
- 底部 dock：新建 / 切换 / 导入 / 输入法。
- 长按主题：重命名、复制、在文件管理器中打开；长按 dock：目录、刷新、外观、帮助。

### 外观
- 只保留「层叠」「舞台」两套皮肤；旧的 `proof` 配置自动回退到层叠。
- 英雄区右上「◑ 外观」胶囊直达换肤。

### 其它
- 包名统一为 `com.trime.editor`（调试包 `.debug`），不再沿用上游
  `com.osfans.trime.editor`；从旧包名迁移需先卸载旧包。
- 内置模板里的快捷键包名同步为 `com.trime.editor/.QuickApplyActivity`
  与 `/.QuickSaveActivity`，调试包换成 `com.trime.editor.debug`。

## 安装
- `adb install -r 同文编辑器-0.4.1.apk`，或直接点击安装。
- 与 0.4.0 同签名（`CN=Trime Editor`），可覆盖升级。
- 首次使用快捷键需要「所有文件访问」权限，按一下会自动跳到系统授权页。

## 已知限制
- 原版同文输入法（3.3.14）不会自动重载主题：生成配色后，需要在输入法设置里
  切一次主题（或切一次输入法），新配色才会画到键盘上。
