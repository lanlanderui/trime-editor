## 本轮另外两个坑

1. **中文 IME 会吞 `adb shell input text`**：设备默认 IME 是同文输入法测试包
   （中文态），第一次脚本点完输入框立刻注入 `0xFF123456`，确定按钮点了但
   文件一行没变——输入框内容没换。稳妥做法是切到英文输入状态（本次临时
   `ime set com.sohu.inputmethod.sogouoem/.SogouIME`），并在点输入框后等
   0.5s 再注入、注入后 dump 核对 EditText 的 text 再点确定。验收完记得把
   IME 切回原值。
2. **uiautomator 的 XML Element 不能用 `if node:` 判空**：没有子节点的
   `<node>` 在 ElementTree 里是 falsy，脚本里 `if seg3:` 永远不执行，看起来
   像「控件不见了」。一律写 `if node is not None`。

## 本轮最大的坑：XML 注释里的 ASCII `--`（值得进 tech-notes）

`bg_dock_primary.xml` 注释里写了 `--s-primary`（CSS 变量名带两个连字符）→ aapt2
`not well-formed` → **`--dir` 编译在第一个坏文件处中止，字母序在它后面的文件全部
「被消失」**（不报错、不警告，只是 packaged_res 里没有、R.jar 里没有字段）。
表现是「Kotlin 引用 UiR.drawable.bg_xxx Unresolved reference」，极难排查——
会让人以为是增量缓存/合并器 bug（我绕了半小时：clean、--no-build-cache、touch、
重命名实验都做了，最后 `aapt2 compile --dir` 手动跑才看见第一行错误）。
**教训**：① XML 注释禁止 ASCII `--`（中文破折号「——」没事）；② 资源「莫名缺失」时
先手动 `aapt2 compile --dir res -o outdir` 看真实错误，别先怀疑构建缓存；
③ 判定实验：把「缺失」文件重命名排到目录最前，若它出现而原第 7 个掉出 → 就是
「前 N 个之后被丢」，与内容无关。

## 正式版 0.4.0 发布 + 包名改为 `com.trime.editor`（23:2x）

**起因**：用户在原版同文输入法配了两个 `command: run` 按键，
`option: "com.osfans.trime.editor/.QuickApplyActivity"` / `.QuickSaveActivity` 报错。
排查：原版输入法用 `ComponentName.unflattenFromString` 展开 `包名/.类名`
（trime3 `app/src/main/java/com/osfans/trime/util/Intent.kt`），**写法没错**；
当时设备只装了 `com.osfans.trime.editor.debug`，没有 release 包 →
`cmd package resolve-activity` 返回 `No activity found`。

用户指出包名归属不对（`osfans` 是原版输入法作者，编辑器是他主导 AI 创作的
独立作品），选了 **`com.trime.editor`** 作为新前缀。趁无存量用户一次改完：
- applicationId / namespace → `com.trime.editor`，editor-ui namespace →
  `com.trime.editor.ui`，debug 后缀仍 `.debug`。
- 5 个源码目录 `git mv`，124 个文本文件的 package/import/R 类/ViewBinding/
  文档/清单注释全局替换；仓库内残留 0 处。
- **保留** `com.osfans.trime.data.theme.*` / `com.osfans.trime.ime.*` /
  `com.osfans.trime.theme.*`（上游库代码，留着才是正确归属）。
- 主清单与 `QuickColorActivity` 的 option 示例、README 新增「输入法按键快捷入口」
  章节与版本配对表同步改。

**顺带修**：`QuickColorActivity` 无「所有文件访问」时从「toast 一句就 finish」
改成直接跳系统授权页（应用页失败退全局页）。本 ROM 不允许 adb 代授该权限
（`appops set` 被 `MANAGE_APP_OPS_MODES` 拦、`pm grant` 对非运行时权限无效），
**首次必须由用户在系统设置开一次**；标准 `/storage/emulated/0/rime` 会被
`ensureThemeDir()` 自动认出。

**新配置（要让用户把两行 option 换成这个）**：
`com.trime.editor/.QuickApplyActivity` / `com.trime.editor/.QuickSaveActivity`；
调试包写 `com.trime.editor.debug/...`。换包名等于换应用，旧包名正式包需卸载，
签名仍是 `CN=Trime Editor`。报告 §12 记录。
